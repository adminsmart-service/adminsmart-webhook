# 🚀 AdminSmart Pro - Centro de Operaciones

Este es el **backend centralizado** de AdminSmart Pro, diseñado para escalar como un servicio SaaS (Software as a Service) para micro-pymes.

## 🧠 Funciones Principales
* **Omnicanalidad:** Gestión de mensajes entrantes de WhatsApp Business API, Facebook Messenger e Instagram Direct.
* **Cerebro IA:** Integración con Google Gemini para respuestas contextuales y humanas.
* **Sincronización en Tiempo Real:** Conexión directa con Firebase Firestore para leer configuraciones de clientes y FAQs sin latencia.
* **Arquitectura Escalable:** Alojado en Render para garantizar disponibilidad 24/7.

## 🛠️ Tecnologías
* **Node.js & Express:** Servidor de alta velocidad.
* **Firebase Admin SDK:** Acceso administrativo a la base de datos.
* **Meta Webhooks:** Recepción de eventos en tiempo real.
